# projeto-base
#Projeto CashBack Grupo 2 (Desenvolvimento de Software)

Sistema de Cashback - Fidelidade Dinâmica📝 DescriçãoEste projeto é uma aplicação Java desenvolvida para automatizar o processamento de vendas mensais e cálculo de fidelidade (Cashback). O diferencial da engine está na lógica de Bonificação Dinâmica, onde o retorno financeiro é calculado com base na categoria do produto e escalonado conforme o gasto total do cliente (Tiers: Normal, Gold e Platinum).🚀 FuncionalidadesImportação de Dados: Processamento de arquivos .csv com múltiplas transações por cliente.Consolidação Automática: Agrupamento de histórico de compras por cliente_id antes do cálculo de recompensas.Motor de Cálculo:Cashback fixo por categoria (Eletrônicos 5%, Vestuário 3%, Outros 1%).Bônus progressivo por Tier (acumulativo para gastos acima de R$ 1.000,00 e R$ 5.000,00).Relatórios: Geração de extratos individuais e exportação de resultados consolidados em CSV.🛠️ Arquitetura e Tech StackO projeto foi estruturado seguindo princípios de Clean Code e Separação de Preocupações (SoC), dividido em pacotes lógicos:model: Classes de domínio (Cliente, Venda, Tier).service: Engine de cálculo e lógica de negócio.persistence: Camada de I/O responsável pelo parsing e geração dos arquivos CSV.view: Interface para interação e visualização do extrato.Tecnologias:Java 17+Maven/Gradle (opcional, dependendo do seu setup)JUnit (para validação do motor de cashback)📊 Regras de Negócio (Engine)O cálculo segue a seguinte lógica matemática:$$Cashback_{Total} = \sum (Valor_{Item} \times \%_{Categoria}) + Bônus_{Tier}$$TierCritérioBônus AdicionalNormal< R$ 1.000Apenas % da CategoriaGold> R$ 1.000R$ 50,00 FixoPlatinum> R$ 5.000R$ 50,00 Fixo + 2% sobre o total📥 Como rodarCertifique-se de ter o JDK 17 ou superior instalado.Clone o repositório.Coloque seu arquivo vendas_mensais.csv na pasta raiz.Execute a classe principal:Bashjavac Main.java && java Main
